THE RUNTIME

Orchestration with
clear boundaries.

Runalith keeps planning, authorization, execution, and acceptance distinct. Each stage leaves durable state that can be inspected when work succeeds, fails, or needs recovery.

CONTROL

Approval is a real gate

A proposal does not start work. Explicit approval compiles an immutable plan; dispatch and deterministic execution are checked against that plan.

Workflow lifecycle →
PERSISTENCE

Durable local state

Tasks, approvals, results, artifacts, and audit events are recorded in SQLite for inspection and recovery.

Architecture →
VERIFICATION

Evidence over assertions

Typed artifact schemas, producer lineage, execution results, and supported success predicates feed completion gates.

Batch execution →
RECOVERY

Failures stay visible

Unknown or incomplete outcomes remain blocked until durable evidence supports a safe next step. Retries preserve plan and provenance.

BUILT FOR MCP

Standard bundle.
Local-first runtime.

The `.mcpb` file is a bundle container for compatible MCP clients. Runalith also supports direct stdio integration, so the package format and the client are separate choices.
