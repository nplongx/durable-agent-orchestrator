# M5 — Security, QA, Platform, Writer

M5 gives the four post-Engineer specialists durable typed artifacts.

## Outputs

- Security → `security-review`
- QA → `qa-report`
- Platform → `platform-review`
- Writer → `documentation`

Each specialist consumes the canonical implementation artifact plus its role-specific planning inputs. Successful native engineering-workflow completion emits the corresponding durable artifact with evidence references to the task result and implementation artifact.

## Scope

M5 records specialist evidence. It does not make acceptance decisions for the later Reviewer/CTO stages and does not alter the execution engine.
